# ARA Driving

## Research before building

This game aims to be based on realism as much as possible. Before designing or building anything that models the real
world (vehicles, crashes, traffic, people, towns, buildings, weather, sound), research the topic first, then build from
what you found.

- Find the real rules and numbers: engineering data, design standards, planning guidance, published studies.
- Put them in the code as named values, with a comment saying what they came from.
- Tell the user what you found and how it shaped the design, with sources, and say when a source is weak or a number is
  only an example.
- Where the game departs from reality on purpose (it's a friendly toy town), say so rather than leaving it to be guessed.

## Generated content

Content is generated by the local model behind a validator, as in `tools/qwen-gen.ts`. Put the rules from the research
into the validator, so the content has to follow them.
